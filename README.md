## Como rodar o projeto

1. Entre na pasta do projeto:
```bash
   cd "Clube Girassol"
```
2. Instale as dependências:
```bash
   npm install
```
3. Inicie o servidor:
```bash
   ng serve
```
4. Abra `http://localhost:4200` no navegador.

- Angular
- TypeScript
- HTML e CSS
